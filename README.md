# CarbonFlow

CarbonFlow is a MERN stack application designed to help users track their daily carbon footprint by logging product emissions.

## Features

- **Carbon Tracking**: Log product usage and estimated carbon emissions.
- **Dashboard**: View total carbon footprint and recent activity.
- **Authentication**: Secure user registration and login.
- **Offline Database**: Self-contained MongoDB setup (no external installation required).

## Tech Stack

- **Frontend**: React, Vite, Tailwind CSS
- **Backend**: Node.js, Express, MongoDB
- **Database**: Local MongoDB (embedded in project)

## Getting Started

### Prerequisites

- Node.js (v14 or higher)

### Installation & Running

1.  Clone the repository.
2.  Install dependencies:
    ```bash
    npm install
    npm run install-all
    ```
3.  Start the application:
    ```bash
    npm start
    ```
    This single command will start:
    - Local MongoDB database (port 27017)
    - Backend Server (port 5001)
    - Frontend Client (port 5173)
